# Domain Model

The project domain centers on graph-native physics learning.

- Topics are website learning objects shown through route pages and graph navigation.
- Graph nodes and graph edges represent fields, topics, concepts, sections, and relationships.
- Topic content may come from Supabase, seed data, archive data, or `TOPIC_CONTENT_OVERRIDES`.
- MCP tools provide AI-facing operations for topics, sections, concept nodes, and graph edges.
- Knowledge reconstruction docs describe a longer-term pipeline for canonical concept graphs and source-specific argument graphs.
