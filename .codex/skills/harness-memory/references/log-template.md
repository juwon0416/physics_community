# Log Template

Use this compact format in `docs/harness/trial-and-error-log.md`.

```markdown
### YYYY-MM-DD - Short lesson title

- Context: What task or artifact exposed the issue.
- False assumption or risk: What could mislead the next agent.
- Signal: The error, symptom, or observation that revealed it.
- Correction: What worked.
- Prevention: The future rule, check, or skill/doc update.
- Related files: `path/to/file`, `path/to/other-file`
```

Keep entries short enough to scan. Link to deeper docs instead of copying long traces.
